병점역 공포맵 생성기 (Devour 스타일)
지원: Unity 6 + URP / Unity 2021.3 + Built-in 렌더 파이프라인 (자동 감지)
=====================================================

[사용법]
1. 유니티에서 이 프로젝트를 열고 스크립트 컴파일이 끝날 때까지 기다립니다.
2. 상단 메뉴  Tools > 병점역 맵 > 맵 생성 (Build Byeongjeom Station)
3. 1~3분 뒤 Assets/ByeongjeomStation/Scenes/ByeongjeomStation.unity 씬이 열립니다.
   - "맵 생성 - NavMesh 제외 (빠름)" : 지형만 빠르게 다시 만들 때
   - "NavMesh 다시 굽기"            : 맵을 직접 고친 뒤 괴물 AI 경로만 다시 구울 때
   - "콜라이더 최적화"              : 현재 씬의 콜라이더 정리 (맵 생성 때는 자동으로 실행됨, 아래 [콜라이더] 참고)
   - "조명 최적화"                  : 현재 씬에 조명 최적화 적용 (맵 생성 때는 자동으로 실행됨, 아래 [조명] 참고)
   - "조명 굽기 (라이트맵)"         : 깜빡이지 않는 조명 · 달빛을 라이트맵에 굽기 / "조명 굽기 되돌리기" 로 원래대로 (아래 [조명 굽기] 참고)
   ※ 다시 생성하면 Generated 폴더와 씬을 덮어씁니다. 손으로 고친 내용이 있으면
     씬을 다른 이름으로 저장(File > Save As)해 두세요.

[맵 구성]  +X = 동쪽(1번 출구/역앞광장), +Z = 북쪽(서울·청량리 방면), 단위 m
- 2층 선상 대합실: 자유통로(맞이방) / 개찰구 / 유료 대합실
  · 서쪽 블록: 남자·여자 화장실, 기계실(문 Door_MachineRoom)
  · 동쪽 블록: 역무실(CCTV 모니터), 직원 휴게실
  · 자유통로 편의점, 승차권 발매기, 역 안내도
- 쌍섬식 승강장 2면: 1·2번(광운대·청량리 방면, 서쪽) / 3·4번(천안·신창·서동탄 방면, 동쪽)
  · 반높이 스크린도어(일부 파손), 지붕, 대기실 유리부스, 자판기, 멈춘 엘리베이터
  · 승강장 양 끝 경사로로 선로에 내려갈 수 있음
- 선로 6개(가운데 2개는 통과선), 전차선, 신호기, 양 끝 과선교 + 바리케이드
- 1번선에 멈춘 4량 전동차 (승강장 쪽 문으로 탑승 가능, 차내 조명 깜빡임)
- 1번 출구: 계단+멈춘 에스컬레이터 → 역앞광장(버스정류장, 시계탑, 버려진 차량, 상가)
- 2·3번 출구: 서쪽, 주차타워, 대학 통학버스 정류장
- 선로 울타리 구멍 2곳(동쪽 z≈-35, 서쪽 z≈40) → 광장↔선로↔승강장 순환 동선

[연출]
- BJ_FlickerLight 컴포넌트: Flicker/Dying/Buzz/Strobe 모드로 조명과 발광 머티리얼이 깜빡임 (Play 중에만)
- 안개(Exponential Squared), 달빛, 어두운 환경광, 후처리(탈색·비네팅·필름그레인·블룸)
  → Window > Rendering > Lighting > Environment, Generated/BJ_PostProcess 에서 조절
- 씬 뷰가 너무 어두우면 씬 뷰 상단의 조명 토글(전구 아이콘)을 끄고 편집하세요.

[콜라이더]
- 맵 생성 때 NavMesh 를 굽기 전에 자동으로 최적화됩니다. 손으로 고친 씬은 Tools > 병점역 맵 > 콜라이더 최적화 (Ctrl+Z 가능)
  · 계단 · 대합실 슬래브의 MeshCollider → BoxCollider. 계단 단들은 경사로 박스 하나 (오르내릴 때 덜컹거리지 않음)
  · 같은 부모 아래 면이 맞닿은 박스는 하나로 합침 (스크린도어 막이, 승강장 바닥층 등). 문 · 통로 같은 빈 공간은 막지 않음
  · 다른 박스 안에 들어간 콜라이더, 바닥에 깔린 얇은 잔해(쓰러진 문짝) 콜라이더 제거, 벤치 등 작은 소품은 박스 하나로
  · Player Settings 의 Prebake Collision Meshes 켬
- Static 이고 트리거 · Rigidbody 가 없는 콜라이더만 건드립니다. 움직일 물체는 Static 을 끄고 넣으세요.
- 합쳐진 콜라이더는 그중 가장 큰 오브젝트에 붙습니다. 최적화 뒤에 작은 쪽 오브젝트를 옮기거나 지워도 충돌은 원래 자리에 남으니,
  그런 오브젝트는 최적화 전에 옮기거나 Static 을 꺼 두세요.

[조명]
- 루트의 BJ_LightCuller 가 Play 중에만 동작합니다 (Tools > 병점역 맵 > 조명 최적화 로 붙임, 맵 생성 때는 자동).
  · 비추는 범위가 카메라에서 일정 거리 밖에 있는 포인트 · 스포트 라이트를 끕니다.
    거리 = 안개 너머라 안 보이는 거리(안개 설정에서 자동 계산)와 Cull Distance(기본 60m) 중 가까운 쪽.
    공포 기본(안개 0.028)이면 약 58m 라 화면 변화가 없고, '분위기: 확인용 (밝게)'(안개 0.006)이면 60m 라
    먼 곳에서 조명이 켜지고 꺼지는 게 조금 보일 수 있습니다. 덜 보이게 하려면 Cull Distance 를 80 정도로 늘리세요 (0 = 안개 거리만).
  · 그림자 거리도 안개 거리와 Max Shadow Distance(기본 80m) 중 가까운 쪽으로 줄이고 (품질 설정 Ultra 는 150m),
    원래의 60% 이하로 줄면 달빛 그림자 캐스케이드를 4 → 2 로 합니다. 씬을 떠나면 원래대로 돌아갑니다.
  · BJ_FlickerLight 는 라이트가 꺼져 있고 발광 물체도 화면에 없으면 계산을 건너뜁니다.
- 스크린도어 · 대합실 외벽 유리처럼 긴 투명 메쉬는 20m 조각으로 나눕니다. 투명 물체는 물체마다 가까운 라이트 몇 개만으로
  칠해지기 때문에, 나누지 않으면 144m 유리 전체가 가운데 라이트로 칠해지고 먼 조명을 끌 때 유리 밝기가 통째로 바뀝니다.

[조명 굽기 (라이트맵)]  Tools > 병점역 맵 > 조명 굽기 (라이트맵) / 조명 굽기 되돌리기 (모두 실시간)
- 깜빡이지 않는 포인트 · 스포트 라이트(BJ_FlickerLight 가 다루지 않는 것, 약 48개)와 달빛을 라이트맵에 굽습니다.
  깜빡이는 조명은 실시간 그대로이고 BJ_LightCuller 가 계속 거리에 따라 끕니다 (구운 라이트는 끌 필요가 없어 빠짐).
  · 구운 라이트는 Play 중 비용이 없습니다 (디퍼드 라이트 패스 · 달빛 그림자 맵이 사라짐). 그림자도 공짜라 켜서 굽습니다
    (라이트가 신호기 렌즈처럼 박스 안에 들어가 있으면 빛이 다 막히므로 그대로 둠).
  · 생성 메쉬는 UV 가 m 단위라 라이트맵 UV(UV2)를 따로 만듭니다. 박스 면마다 한 조각, 같은 평면에서 맞닿은 면은 한 조각으로 묶어
    실제 크기 비율 그대로 채워 넣습니다 (4텍셀/m, 구운 라이트가 안 닿는 물체는 2텍셀/m).
  · 작은 소품 · 내장 원기둥/판(UV2 없음) · 유리 · 데칼 · 움직이는 물체(괴물 · 플레이어)는 굽기에서 빼고,
    자동으로 깐 라이트 프로브(Atmosphere 아래 BJ_LightProbes)로 구운 조명을 받습니다.
  · 라이트맵은 Scenes/ByeongjeomStation 폴더에 저장됩니다. 굽는 동안 에디터를 쓸 수 있고, 끝나면 씬을 저장합니다.
- 환경광 · 달빛도 함께 구워지므로 '분위기' 메뉴로 바꾸면 다시 구워야 합니다 (안개는 Play 중 계산이라 상관없음).
  '확인용 (밝게)' 상태에서 굽기를 누르면 공포 기본으로 바꿀지 묻습니다.
- 메모리: 라이트매퍼는 메모리가 모자라면 오류 없이 진행률 0% 에서 멈춘 채 기다립니다 (Console 에 '... out of memory').
  남은 메모리가 4GB 보다 적으면 굽기 전에 경고합니다. 브라우저 · 채팅 앱 등을 닫고 구우세요.
- 굽기를 취소하면 라이트 설정은 원래대로 돌아갑니다. 되돌리기는 라이트 · Lighting Settings · Contribute GI · 라이트 프로브 ·
  라이트맵 · 라이트맵 UV 를 모두 원래대로 돌리고 씬을 저장합니다.
- 구운 뒤 라이트 위치 · 색 · 세기나 지오메트리를 고쳤으면 같은 메뉴로 다시 구우세요.
- '맵 생성 때 조명도 굽기' 를 체크하면 맵 생성 끝에 자동으로 굽습니다 (PC별 설정, 기본 꺼짐. 몇 분 더 걸림).

[플레이어를 넣을 때]
- "PreviewCamera" 오브젝트는 확인용입니다. 플레이어 카메라를 넣으면 꺼 주세요(AudioListener 중복 방지).
- 플레이어 카메라: Rendering > Post Processing 체크, Background Type = Solid Color(안개색) 권장
- 프로젝트가 새 Input System 전용(activeInputHandler=1)이므로 플레이어 스크립트는 Keyboard.current / Mouse.current 사용
- NavMeshSurface 는 루트(ByeongjeomStation_병점역)에 있고, Humanoid 에이전트 기준으로 구워집니다.

[참고]
- 실제 병점역 구조(2층 선상역사, 쌍섬식 승강장, 1번 출구=역앞광장, 2·3번 출구=서쪽)를 바탕으로
  게임용으로 단순화·재배치한 맵입니다. 승강장 번호/방면, 실 배치 등은 실제와 다를 수 있습니다.
- 간판·광고·포스터·상호는 모두 가상의 것입니다.

[Built-in 렌더 파이프라인 프로젝트 (예: Unity 2021.3 기본 3D)]
- URP 가 없으면 자동으로 Standard 셰이더를 쓰고, 후처리(Volume)는 생략합니다.
- 실시간 조명이 많아서 카메라를 Deferred 로 렌더링합니다. Deferred 에서는 Lighting 창의 안개가
  불투명 물체에 적용되지 않으므로 BJ_DeferredFog 컴포넌트(Shaders/BJ_DeferredFog.shader)가 같은 안개를 입힙니다.
  → 플레이어 카메라에도 BJ_DeferredFog 컴포넌트를 붙이세요 (붙이면 자동으로 Deferred 로 바뀜).
- AI Navigation 패키지가 없으면 내장 NavMesh 빌더로 (콜라이더 기준) 굽고, 씬 자체의 NavMesh 로 넣어 씬과 함께 로드됩니다.
  NavMeshAgent 는 그대로 사용할 수 있습니다. (Navigation 창의 Clear 를 누르면 지워지니 'NavMesh 다시 굽기' 로 다시 구우세요)

[VR - 메타 퀘스트 (PC 연결: Quest Link / Air Link)]
1. 맵 생성 후  Tools > 병점역 맵 > VR (메타 퀘스트) > VR 플레이어 추가 (VR 모드 켜기)
   - 역앞광장(1번 출구 앞)에 'VR_Player (Meta Quest)' 가 생기고 미리보기 카메라는 꺼집니다.
   - VR 모드가 켜져 있으면 이후 '맵 생성'을 다시 해도 VR 플레이어가 자동으로 들어갑니다 (PC별 설정).
   - 끄기: VR (메타 퀘스트) > VR 모드 끄기
2. 처음 한 번만 설정 (메뉴의 '설정 체크리스트 보기'에도 같은 내용):
   - Project Settings > XR Plug-in Management 설치 → PC 탭에서 OpenXR 체크
   - OpenXR > Enabled Interaction Profiles 에 'Oculus Touch Controller Profile' 추가, 경고가 있으면 Fix All
   - Built-in 파이프라인 프로젝트는 OpenXR Render Mode 를 Multi-pass 로 (URP 는 기본값 그대로)
   - PC 의 Meta Quest Link 앱 > 설정 > 일반 > OpenXR 런타임을 Meta Quest Link 로
3. 퀘스트를 Link/Air Link 로 연결하고 Play
[조작] 왼쪽 스틱 이동 / 왼쪽 스틱 누르기 달리기 / 오른쪽 스틱 좌우 45도 스냅 회전 / A 버튼 손전등
       이동·회전할 때 시야 가장자리가 어두워지는 멀미 완화 효과 (BJ_VRRig 의 Comfort Vignette 로 조절)
[헤드셋 없이 테스트] WASD 이동, 마우스 시점(클릭=커서 잠금, Esc=해제), Shift 달리기, F 손전등
- URP 프로젝트에서는 VR 에서 어지러운 필름그레인·색수차·비네트 후처리를 자동으로 끕니다.
- 퀘스트 단독 실행(Android 빌드)은 실시간 조명이 너무 많아 지원하지 않습니다 (PC 연결 전용).
